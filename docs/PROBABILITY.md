# 单位正方形均匀取点模型下的解数概率

## 1. 随机模型

四点在单位正方形 $K=[0,1]^2$ 内独立均匀取样。目标正方形可位于平面任意位置，四点分别位于其四条边的严格内部。

记 $\mathcal C$ 为四点组成严格凸四边形的事件，$q$ 为唯一解的无条件概率。表中所有概率均以全部四点输入为分母。

“唯一候选正方形”由四点的边线关联条件确定。对角线不垂直时，它始终唯一，四点分别位于对应边的支撑直线上，合法性由严格边段条件决定。[候选与位置判据](CLASSIFICATION.md#13-等价的坐标判据)

合并全部无解情况，以及以严格凸为条件，分别得到

$$\mathbb P(\text{无解})=1-q\approx0.8972049322386,$$

$$\mathbb P(\text{唯一解}\mid\mathcal C)=\frac{36q}{25}\approx0.1480248975765,$$

$$\mathbb P(\text{无解}\mid\mathcal C)=1-\frac{36q}{25}\approx0.8519751024235.$$

全部无解约为 89.7204932%。在严格凸条件下，唯一解约为 14.8024898%，无解约为 85.1975102%。

## 3. 解析依据

单位正方形中随机三角形的平均面积为 $11/144$。第四点落入其内部的概率等于这一平均面积，因此

$$\mathbb P(\mathcal C)=1-4\cdot\frac{11}{144}=\frac{25}{36},\qquad
\mathbb P(\text{非退化非凸})=\frac{11}{36}.$$

重合、三点共线和对角线垂直均由非零多项式方程限定，在连续模型下为零概率。唯一解闭式通过正方形参数化化为一维有理函数积分，再以精确多面体矩和符号恒等式核验。[完整推导](PROBABILITY_PROOF.md) · [解析证书](../experiments/results/probability_analytic.json)

## 4. 蒙特卡洛核对

使用 NumPy 2.2.4、PCG64、种子 $2026111101$ 抽样一亿组，结果列于上表。估计量分别为

$$\widehat q=\frac{N_U}{N},\qquad
\widehat p=\frac{N_U}{N_C},$$

其中 $N$ 为总样本数，$N_C$ 为严格凸样本数，$N_U$ 为唯一解样本数。[完整计数与置信区间](../experiments/results/probability_all_inputs_monte_carlo.json)

批量判定使用浮点运算，并将前 $1,024$ 组随机输入及 $1,820$ 组二进制有理网格输入与 SageMath 精确分类逐项比较，六类判定全部吻合。

最大偏差约为 $0.0112$ 个百分点。凸一般无解项偏差为 $-2.28$ 个标准差，其单项 95% Wilson 区间未覆盖解析值。三项正概率的联合 Pearson 统计量为 $5.44394$，自由度为 $2$，渐近尾概率为 $0.0657451$。原始记录完整保留。

早期种子 $20261111$ 的一亿组结果见 [历史抽样记录](../experiments/results/probability_unit_square.json)。

## 5. 复现

在项目根目录使用 SageMath 10.7，依次运行解析核验和蒙特卡洛。Docker 环境见 [运行与核验](../README.md#运行与核验)。

```sh
sage -python experiments/analytic_probability.py --write experiments/results/probability_analytic.json
sage -python experiments/estimate_probability.py --samples 100000000 --seed 2026111101 --write experiments/results/probability_all_inputs_monte_carlo.json
```

解析脚本增加 `--monte-carlo experiments/results/probability_all_inputs_monte_carlo.json` 可将联合统计检查写入证书。抽样量、批大小和种子分别由 `--samples`、`--batch-size`、`--seed` 指定。
